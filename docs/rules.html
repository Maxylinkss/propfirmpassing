Rule records

Evaluation rules, recorded by date and by plan

Rules are listed per plan rather than per brand, because at most firms the plan name is the rulebook. A firm running four products has four different sets of rules, and treating the brand as one ruleset is the most common way an avoidable breach happens.

Firms deliberately left without figures in this snapshot

These firms run several products under one brand, each with its own rulebook. Rather than publish a number that may belong to a different plan, no figure is shown until it has been read from that specific plan's documentation.

Read the drawdown column before the target column. The target tells you where the finish line is. The drawdown type tells you whether you reach it. An intraday trailing threshold responds to unrealised profit, so a retracement can end an account on a day that finishes net positive — two firms with the same target and the same threshold can be completely different assignments.
